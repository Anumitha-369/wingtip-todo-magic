# 🧠 Project Info – TASK MASTER

## 📝 [To-Do List Web Application]

🌐 Live URL: [TaskMaster on Netlify](https://6907c1b7be9f34cfb32b16b3--effervescent-gecko-13cbe3.netlify.app/)

----

🚀 Technologies Used :

This project is built with:

⚡️ Vite – Fast build tool

🧠 TypeScript – Type-safe JavaScript

⚛️ React – Frontend library

🎨 shadcn/ui – UI components

💨 Tailwind CSS – Utility-first styling

🐳 Docker – Containerization


- Frontend	     - React + Vite + TypeScript + Tailwind

- Backend	         - Node.js + Express.js

- Database	     - MongoDB

- Deployment	     - Netlify (frontend), Render (backend), Docker (recently added)

----

Requirement: Node.js & npm installed 👉 Install with nvm

----

## Features

🎨 <B>Theme Selection Choose from 5 unique themes:<B>

> Default Gradient

> Natural

> Multicolor

> Calm & Subtle

> Floral Black

> Cartoon Fun

- 📝 Add Tasks Quickly add new tasks with a clean input interface.

> ✅ Mark as Complete Track progress visually by marking tasks as done.

- 🗑️ Delete Tasks Remove tasks instantly for a clutter-free experience.

- ⏰ Snooze & Reminder Logic Reset snooze time and receive notifications or alarms based on the updated schedule.

## 🛠️ Getting Started

In Terminal , 

Step 1: Clone the repository using the project's Git URL.
git clone <YOUR_GIT_URL>

Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

Step 3: Install the necessary dependencies.
npm i

Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
